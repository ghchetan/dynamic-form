Accurex Dynamic Form

Forms configured in the CRM, rendered on the website

The CRM sends a form as JSON and the website draws it: questions, pass/fail rules, unit tabs, a deficiency list and workflow buttons. It keeps working offline. The demo below is the Accurex Start-Up Report used when commissioning kitchen ventilation equipment.

Live demo Accurex Start-Up Report Four units (CP-1, HD-1, EF-1, MUA-1) with checks, readings, photos and a reviewer step. Open the demo → Documentation Developer docs Tutorials, configuration and JavaScript API reference, and deployment guides. Press ⌘K to search. Read the docs →

Things to try in the demo

  • FlaggedOn CP-1, answer No to "Power to lights?". The tab turns red and the problem appears in the deficiency list at the top. View jumps back to it.
  • CheckEnter 18.2 and 19.5 in "EF Fan 1 overload setting": a 7.1% deviation, inside the amber band.
  • PassClick Save draft and reload: your answers come back. Then try Submit for review, or the reviewer's Approve and Reject.
